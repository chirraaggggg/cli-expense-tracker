# CLI Expense Tracker

A simple command-line expense tracker built with Node.js.

## Features

- Add expenses
- List expenses
- Filter by category
- Filter by month
- Update expenses
- Delete expenses
- View spending summaries
- Category-wise spending
- Set monthly budgets
- Track budget usage
- Detect overspending
- Persistent JSON storage

## Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd cli-expense-tracker
